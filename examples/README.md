# Examples

| Script | Needs | Shows |
|---|---|---|
| [`offline_demo.py`](offline_demo.py) | nothing | The JWT scenario with a scripted model and the real harness; add `--mermaid` for a diagram |
| [`claude_quickstart.py`](claude_quickstart.py) | `widethink[anthropic]`, an Anthropic key | A real run on your project with live events, recording and a saved result |
| [`openai_compatible.py`](openai_compatible.py) | `widethink[openai,local]`, a local vLLM or Ollama server | Fully local: open model, local embeddings, private context |
