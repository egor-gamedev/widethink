# widethink

**Широкое мышление для LLM по образцу цифрового мозга** — прослойка, которая
замечает, где стандартное решение не подходит *именно этому пользователю*.

[English version](README.md)

---

Попросите модель «добавить JWT-аутентификацию в наш API» — она ответит по
учебнику: access-токены на 15 минут, ротация refresh-токенов. Правильно — если
только ваши техники не проводят по четыре дня в подвалах без связи, не берут
общие планшеты со склада, а политика безопасности не требует отзывать доступ за
час. Всё это есть в проекте. Модель туда не смотрит: она выбирает решение,
сильнее всего связанное с формулировкой запроса, и у неё нет механизма, который
заставил бы посмотреть в сторону.

widethink встаёт между пользователем и моделью. Модель остаётся как есть;
прослойка решает, **о чём модели думать на каждом шаге**, — так, как это делает
поток мысли [цифрового мозга](docs/mechanisms.md): дерево мыслей, которое идёт
вглубь жребием, устаёт от повторов, затухает с глубиной, возвращается на уровень
выше, захватывается неожиданным и начинает половину новых веток с деталей
контекста пользователя.

## Как это работает

| Механизм мозга | Что делает в прослойке |
|---|---|
| Жребий вместо максимума | Следующая идея выбирается с весом `(связь × свежесть × ценность)²` — сильные связи чаще, но не всегда |
| Усталость («надоело») | Ветка, чьи предложения повторяют уже обдуманное, закрывается |
| Торможение возврата | Обдуманное показывается модели как «уже рассмотрено», дубликаты отсекаются |
| Затухание с глубиной | Сила ×0.86 за уровень; слабые и глубокие мысли предлагают меньше и останавливаются раньше |
| Тяга к ценному | Идеи, важные *этому* пользователю, выбираются примерно в 20 раз чаще, плохие — реже, но не никогда |
| Захват неожиданным | Найденное противоречие становится следующей мыслью |
| Всплытие от воспринятого | Новые ветки стартуют от файла, политики, фразы пользователя: «что из этого следует?» |
| Вопросы | То, что нельзя решить по контексту, становится вопросом пользователю |

Все механизмы и их константы взяты из мозга с выводом каждой —
[docs/mechanisms.md](docs/mechanisms.md). Архитектура —
[docs/architecture.md](docs/architecture.md).

## Быстрый старт

```bash
pip install "widethink[anthropic]"        # или [openai], или [all]
```

Без ключа API — заскриптованная модель разыгрывает сценарий с JWT, а думает
настоящая прослойка:

```bash
python examples/offline_demo.py
```

С Claude:

```python
from widethink import Thinker
from widethink.llm import AnthropicLLM

result = Thinker(AnthropicLLM()).think(
    "Добавь JWT-аутентификацию в наш API", "./my-project", budget=60_000
)
print(result.answer)  # решение
print(result.deviations)  # где и почему отступили от шаблона
print(result.questions)  # что спросить у пользователя
print(result.render())  # дерево мысли
```

Из командной строки:

```bash
widethink think "Добавь JWT-аутентификацию в наш API" -c ./my-project --budget 60000
```

## Бенчмарк «скрытых требований»

Утверждение нужно доказать измерениями — **при равном бюджете токенов** против
сильных базовых методов. Поэтому в репозитории есть бенчмарк: задачи, где
стандартное решение неверно для пользователя из контекста, и контрольные задачи,
где оно верно (придуманные требования штрафуются). Методика —
[docs/benchmark.md](docs/benchmark.md).

## Статус

**Альфа, исследовательский код.** Архитектура, все механизмы, провайдеры, учёт
бюджета и бенчмарк реализованы и покрыты тестами. **Результатов пока нет**:
побеждает ли широкое мышление обычную модель при равном бюджете — ровно то, что
предстоит измерить по [плану](ROADMAP.md).
